# 『Giyomu Game』さんから公開されているスマホのインディーパズルゲーム『Frog Puzzle』の簡易的なwebアプリ版を目標にした取り組みです。

現在制作中。AIに指示を出してコードを書かせることと、画面に動きのあるプログラムを作る経験をすることを目的に制作しています。

## 🚀 公開URL
https://freedial0101-source.github.io/frog-puzzle-system-study/

## 📌 現在の状況
AIに指示を出してコードを書かせたところです。
ステージを作る機能までは上手くいきましたが、駒(カエル)を動かすアルゴリズムは上手くいきませんでした。
ただし、駒の動きのアルゴリズム自体は自分で書いてものがあります（※こちらは、動きを表示する機能がありません）。
メインプログラムには、現在ステージ作成機能までを載せます。


## 📋 これからの予定
- 木曜日までには、基本機能を完成させるつもりです。

## 📂 リポジトリの構成
* **index.html**：メインプログラム（作成中）
* **frog's program I wrote.html**：私が書いたカエルの動き方のアルゴリズムです。（こちらは動きを表示する機能がありません。）
* **プロンプトメモ**:AIに出したプロンプトに関してのメモです
